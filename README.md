# Oʻzbek tili Language Pack for VS Code

🇺🇿 **Visual Studio Code uchun Oʻzbek tili paketi**

Bu kengaytma VS Code interfeysi-ni toʻliq oʻzbek tiliga oʻgiradi.

## ✨ Xususiyatlari

- **To'liq UI Lokalizatsiya**: Menyu, buyruqlar, sozlamalar va boshqalarning barchasi
- **Qidor Qidirish**: Qidirish va almashtirish funksiyalari
- **Terminal Qo'llab-quvvatlash**: Terminal buyruqlari
- **Git/Source Control**: Manba nazorati tillib
- **Debug Alatlari**: Nosyaxonalik funksiyalari
- **Extensions Boshqaruvi**: Kengaytmalar menejeri
- **Sinov Alatlari**: Test ishga tushirish alatlari

## 🚀 O'rnatish

### Option 1: VS Code Marketplace-dan

1. VS Code-ni ochish
2. `Ctrl+Shift+X` bosing (Extensions)
3. "Uzbek Language Pack" qidiring
4. **Install** bosing
5. VS Code-ni qayta ishga tushiring

### Option 2: VSIX Faylddan

1. [Bu repositoriyadan](https://github.com/sardorazimov/vscode-language-pack-uz) `vscode-language-pack-uz-0.0.1.vsix` ni yuklab oling
2. VS Code-da `Ctrl+Shift+X` bosing
3. "..." menyu → **Install from VSIX** tanlang
4. VSIX faylni tanlang

## ⚙️ Tilni Faollashtirish

1. `Ctrl+Shift+P` bosing (Command Palette)
2. "Configure Display Language" yoki "Display Language" qidiring
3. **Oʻzbek tili** (uz) tanlang
4. VS Code-ni qayta ishga tushiring
